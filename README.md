# Open Pocket

Open Pocket is an open-source Android companion for people who love their Pocket AI recorder and want to use it without a subscription. It will sync recordings to a self-hosted AI agent for transcription, notes, and memory.

The app is in preparation; there is no installable Android release yet. Product requirements and the implementation will follow.

Your recordings and device credentials are private. This repository must never contain binding keys, passwords, access tokens, or audio pulled from a recorder.

See [docs/README.md](docs/README.md) for the documentation map and recorder protocol references.
